Helpers that run on your PC.

Plain rules and file metadata, no AI and no cloud. Each one suggests first and moves only when you say so.

  • Bin suggestionsEvery new file gets a suggested bin, with the reason and a confidence.
  • TidyOne command sorts the sure things and leaves the rest for you.
  • Smart renameNames from a PDF’s title, a photo’s date or where a download came from.
  • Rule suggestionsLearned from your own moves, so it follows your habits.
  • Desk healthFinds stale, duplicate and oversized files and plans an archive.
  • Near-duplicate imagesGroups photos that are almost the same, so you keep the best one.
  • Project foldersSpots files that share a name prefix and offers a bin and a rule for them.
  • Installer clean-upOld setup files and archives you already unpacked, ready to put away.

Show first. Move second. Undo always.

  1. PreviewTidy, rules and the command bar all show exactly what will move where, with a reason and a confidence. Low confidence says “needs you” instead of guessing.
  2. JournalEvery applied change is written to a local journal, so noDesk can always tell you what it did and when.
  3. UndoOne shared Ctrl + Z across every move, from any panel.

Archive only

noDesk never deletes. Old and duplicate files move to an archive you can browse and restore from.

Local only

No account, no cloud AI, no telemetry. The only network traffic is the update check.

Easy in, easy out

A per-user installer that needs no admin rights. Uninstalling leaves your files and bins exactly where they are.
